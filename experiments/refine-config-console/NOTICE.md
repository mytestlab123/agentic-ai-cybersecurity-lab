# UI attribution

`src/ui.tsx` contains locally adapted, reduced shadcn/ui Button and Sheet
compositions (Radix primitives, class-variance-authority and Tailwind). Only
the variants needed for this read-only experiment are kept. No CLI/plugin is
required at runtime. See [Button](https://ui.shadcn.com/docs/components/radix/button)
and [Sheet](https://ui.shadcn.com/docs/components/radix/sheet).

## Local SVG icons

`src/icons.tsx` adapts the `shield-check` and `server` paths from
[Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
The remaining simple geometric interface symbols are local compositions.
They are service cues, not official AWS logos. All SVG is bundled locally;
there is no icon CDN, font download, new package or provider-supplied SVG.
